🍽️ Calorite
Smart Calorie & Protein Tracker

Calorite adalah aplikasi pencatat nutrisi harian cerdas yang dirancang untuk membantumu memantau asupan kalori dan protein dengan presisi. Menggabungkan teknologi AI image recognition dan antarmuka yang dinamis, Calorite memastikan program diet atau bulking-mu tetap on-track tanpa ribet, bahkan untuk makanan asrama atau katering yang komposisinya susah ditebak.

✨ Key Features
📸 AI Food Snapshot (Capture)
Malas input manual? Cukup foto makananmu! Calorite dilengkapi dengan AI yang dapat mengestimasi jumlah kalori dan protein secara otomatis dari foto makanan, lalu menyimpannya langsung ke riwayat harianmu. Anda juga bisa membantu AI mengenali makananmu dengan menginput konteks setelah memilih/memfoto makanan!

✍️ Manual Entry Fallback (Add Manually +)
Terkadang AI bisa keliru, atau kamu hanya makan cemilan kecil. Fitur input manual memungkinkanmu memasukkan angka kalori dan protein (dalam gram) secara presisi. Data akan tersimpan rapi dengan smart placeholder agar database HP tetap ringan dan anti-crash.

🗒️Recipe Notes
Capek bolak balik ke browser atau media sosial untuk mencari resep favorit? Tinggal tambah kedalam Recipe Journal dalam aplikasi aja! Calorite juga berfungsi sebagai catatan resep untuk recook makanan-makanan favorit kamu!

📊 Dynamic Progress Visualizer
Pantau target nutrisi harianmu (misal: 2000 kcal & 100gr Protein) melalui Dashboard interaktif. Gambar piring dan makanan akan terisi warnanya secara proporsional dari kiri ke kanan seiring dengan bertambahnya asupan makananmu hari itu.

🗓️ Comprehensive Daily History & Notes
Lacak kembali apa saja yang kamu makan di hari-hari sebelumnya. (Up to 7 days sebelum aplikasi menghapus datamu secara otomatis agar tidak memakan banyak space)
Dilengkapi dengan daftar horizontal scrolling untuk menu harian.
Full-screen Image Preview: Klik makanan untuk melihat foto aslinya secara penuh.
Daily Journal: Tambahkan catatan evaluasi dietmu di akhir hari.

🔔 Smart Meal Reminders
Jangan sampai kelewatan jam makan! Calorite menggunakan sistem AlarmManager di latar belakang untuk mengirimkan Push Notification (High Priority) tepat di jam makan (07:00, 12:00, 16:00, dan 20:00) untuk mengingatkanmu memfoto makanan.

💾 Optimized Local Database
Dibangun dengan Room Database SQLite yang dioptimalkan untuk performa tinggi. Aplikasi secara cerdas membedakan foto jepretan asli (disimpan dalam format Base64) dan entry manual untuk menghemat memori penyimpanan secara signifikan.
